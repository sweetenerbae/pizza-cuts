# Пицца поровну

Адаптивный калькулятор равных кусочков пиццы. Расчёты выполняются в браузере; регистрация и база данных не нужны.

## Разработка

Node.js 22.13+:

```sh
npm ci
npm run dev
```

## Статическая сборка

```sh
npm run build
```

Готовый сайт находится в `dist/client/`. Размещайте содержимое этой папки на обычном веб-сервере. Node.js на сервере не нужен. Шрифты и изображения входят в сборку.

## Размещение

Домен: https://pizza-porovnu.ru

Файлы сайта хранятся отдельно от STU: `/srv/pizza-porovnu/releases/`. Символическая ссылка `/srv/pizza-porovnu/current` указывает на активную сборку. В контейнер Caddy монтируется `/srv/pizza-porovnu:/srv/pizza-porovnu:ro`. Блок конфигурации сайта приведён в `deploy/Caddyfile`.

Для домена и `www` нужны A-записи на IP сервера. Caddy автоматически выпускает HTTPS-сертификат после настройки DNS. При смене сервера проверяйте IP перед обновлением записей.

Для обновления загрузите новую сборку в отдельную папку `releases/` и переключите `current`. Предыдущая папка остаётся для отката.
